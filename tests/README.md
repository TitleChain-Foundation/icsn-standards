# Validation Tools

![Hardware endpoint trust public review](../assets/public-review/hardware-endpoint-trust.svg)

Validation proves only the cases exercised. It does not establish truth,
authority, security, legal compliance, certification, or production readiness.

| Tool | Purpose |
| --- | --- |
| [Hardware endpoint package validator](validate_hardware_endpoint_package.py) | Validates the three synthetic hardware endpoint examples against their Draft 2020-12 schemas |
| [Article 12 CER package validator](validate_article12_cer_package.py) | Validates the synthetic transaction snapshot and fail-closed separation of control, title, claims, notice, filing, transfer authority, and six-gate authorization |
