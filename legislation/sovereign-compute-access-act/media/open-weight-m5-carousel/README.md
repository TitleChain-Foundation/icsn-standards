# Open Weights and M5 Classification Carousel

**Public-review media - registry snapshot verified September 14, 2026.**

This package contains the latest 16-card Open Weights and M5 Classification
carousel plus its standalone poster. Every PNG is 2160 x 2700 pixels. The
carousel connects open-weight compute tiers, the Sovereign Intelligence Stack,
and M5 data classification.

The model registry is informative and non-normative. Re-verify model releases,
licenses, parameter counts, and context limits before production or regulatory
reliance.
