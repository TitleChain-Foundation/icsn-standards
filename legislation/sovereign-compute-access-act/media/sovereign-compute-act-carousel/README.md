# Sovereign Compute Access Act Carousel

**Draft v1 public-review media - published September 14, 2026.**

This 16-card vertical carousel introduces the Sovereign Compute Access Act,
its compute tiers, registry principles, hardware-neutrality approach, and
selected implementation proposals. Each PNG is 2160 x 2700 pixels and may be
viewed, downloaded, or shared with attribution.

The carousel is explanatory outreach material, not model-act text. Cards 9-13
present **Proposed Section 106(a)-(e)** concepts for public discussion. Those
provisions are not part of the current Draft v1 official text, which ends Title
I at Section 105.
