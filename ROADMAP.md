# Public Roadmap

This roadmap describes near-term public work. It is directional, may change through review, and does not promise delivery dates or funded positions.

## Now

- Triage open issues and identify well-scoped `good first issue` and `help wanted` tasks.
- Review the v0.1.0 public package for broken links, ambiguous maturity labels, and missing license designations.
- Improve the RFC index and apply consistent Draft, Candidate, Stable, or Deprecated status labels.
- Add representative examples and negative test cases to existing schemas.
- Define minimum security, privacy, and conformance sections for every RFC.

## Next

- Publish conformance criteria and test vectors for a selected Draft RFC.
- Create a small, license-designated reference implementation or validation utility.
- Document interoperability and recovery scenarios.
- Invite independent security and privacy review.
- Publish the first sponsor-impact note after sponsored public work is delivered.

## Later

- Advance qualifying RFCs through public review based on evidence.
- Expand cross-implementation testing.
- Publish versioned conformance profiles and implementation reports.

## Contribute

Start in [Foundation Discussions](https://github.com/orgs/TitleChain-Foundation/discussions) for questions, feedback and early proposals. Use [CONTRIBUTOR-PATHWAYS.md](CONTRIBUTOR-PATHWAYS.md) to find scoped work, then follow [CONTRIBUTING.md](CONTRIBUTING.md) for RFC or pull-request changes.
