# Recommendation-specific public-review Issues

Create one GitHub Issue from each numbered Markdown file in this directory. Keep evidence and analysis separated by recommendation so objections, implementation questions, legal review, and proposed revisions remain traceable.

Apply labels from each draft. Available labels should include `regulatory-review`, `sec`, `public-comment`, `evidence-request`, `implementation-analysis`, `legal-review`, and `resolved`.

Do not request or post private financial information, identity documents, privileged communications, investor information, or nonpublic agency correspondence.
