# M5AgentClub — First 100 Activation

> **Phase One activation model.** M5AgentClub is the first structured activation environment for the M5 Freedom Office. The first 100 members will help test, harden, document, and improve the complete member journey before broader scale.

## Why M5AgentClub

Chase Aldridge and Kem Tousson already operate **Glitch Cat Club on Skool**. M5AgentClub will use that existing cohort-operating experience to launch the first M5 activation program on Skool.

This is not intended to be a course that sits apart from the product.

**The course is the activation.**

The first 100 members will move through the same M5 environment that the product, engineering, accounting, blockchain, graph, and curriculum teams are building.

The operating loop is:

```text
learn
  ↓
activate
  ↓
use
  ↓
approve
  ↓
do real work
  ↓
capture evidence
  ↓
find friction
  ↓
improve the product + activation workflow
  ↓
re-test
  ↓
scale
```

# The Phase One M5 Experience

## M5 Desktop = Home

The desktop environment is the member's primary **Freedom Office**.

It is where the deeper local-first operating environment lives:

- M5POD;
- **M5Brain** — member-controlled knowledge, memory, relationships, graph, documents, credentials, permissions, and operating context;
- local model runtime;
- open-weight models;
- M5Agents;
- MCP / OpenAPI tools;
- workflow engine;
- M5Scribe procedures;
- approved integrations;
- business files and evidence;
- accounting / ledger interfaces; and
- the local node / service state.

The desktop is the persistent work environment.

## M5 Mobile = Key + Passport + Approval + Communication

The mobile experience is not intended to duplicate the full desktop.

It is the trusted companion that lets the member remain in control while away from the desktop.

From the phone, the member should progressively be able to:

- **open my Passport**;
- **authenticate myself**;
- **talk to my agent**;
- **see an action awaiting approval**;
- **approve or reject an action**;
- **review agent activity**;
- **receive notifications**;
- **present a credential**;
- **complete or update M5-CV evidence**;
- **access my Bank of Me**;
- **revoke permissions**;
- **see whether my Freedom Office / node is online**;
- **receive approved credentials after completing program requirements**;
- **unlock the next course or capability pathway**;
- **progress toward certified M5Agent status if I choose to onboard or teach others**; and
- **use an updated M5-CV to pursue a new role, contract, or job opportunity**.

The mobile design principle is:

**the phone proves, approves, communicates, and revokes; the desktop remains the deeper sovereign work environment.**

- **Mac — Apple Silicon**
- **Windows — x64**
- **Windows — ARM64**

## Tier 2 — Certified Linux targets

- **Ubuntu Linux — x64**
- **Ubuntu Linux — ARM64**

## Companion

- **iPhone / iPad**
- **Android**

## Access / Fallback

- **browser / PWA**

The certification label should describe the **reference environment tested by the program**. It should not imply that every device, Linux distribution, hardware configuration, or third-party integration is supported.

# One Course, One Golden Workflow, Multiple Installation Adapters

The curriculum should not fork into six separate courses.

Every M5Scribe procedure should be tagged:

```text
MAC | WIN-x64 | WIN-ARM | LINUX | ALL
```

Most curriculum content should be:

```text
ALL
```

Only the parts that genuinely differ by operating system should fork, such as:

- installation;
- file-system permissions;
- disk or file encryption;
- local runtime installation;
- hardware-specific configuration;
- OS security permissions;
- background services;
- certain local integrations; and
- OS-specific recovery steps.

The Phase One rule is:

> **One M5 Freedom Office course → one golden workflow → several installation adapters.**

That keeps the member experience coherent while still respecting the realities of each operating system.

- M5Scribe procedures;
- agent-operation evidence;
- M5POD / Freedom Office activation;
- project work;
- TitleChain provenance;

The purpose is not to create another closed résumé database.

# Certified M5Agent Pathway

A member who wants to go beyond personal use may apply to progress into the M5Agent pathway.

Possible progression includes:

- advanced M5Agent classes;
- specialized role or industry modules;
- onboarding / activation training;
- trainer or instructor qualification;
- product or implementation roles;
- M5-CV job or contract opportunities; and
- operation of an independent M5-aligned service or business.

Completion of a course alone does not automatically confer a certification, employment, compensation, or authority to onboard others.

Certification should require the applicable:

- course completion;
- evidence;
- practical demonstration;
- security and privacy requirements;
- role-specific criteria;
- trainer approval where applicable; and
- current credential status.
