# M5Ecosystem Approval Boundary

This repository is the public TitleChain Foundation commons. It contains public standards, RFCs, schemas, governance records, conformance material, and reference work that is explicitly designated for public review or open-build use.

M5Ecosystem is a separate implementation and approval authority. It controls access to private or restricted M5 systems and determines whether special licensing is available for proprietary implementations, production services, commercial deployments, restricted APIs, credentials, member systems, and private partner or investor material.

## Public Commons Access

Anyone may read, review, discuss, fork, or contribute to material according to the designation in [LICENSE.md](LICENSE.md) and [LICENSES/LICENSE-MATRIX.md](LICENSES/LICENSE-MATRIX.md). Public GitHub participation does not create an M5 account, credential, employment relationship, production entitlement, or special license.

## Separate Approval

Use of an M5Ecosystem-controlled component requires written approval and the applicable license from the M5Ecosystem authority. A public Foundation specification, RFC, schema, link, sponsor relationship, or reference implementation does not grant permission to deploy or redistribute a restricted M5 component.

Requests for private implementation access, production credentials, commercial licensing, or M5 member-system access must use the separate M5Ecosystem approval channel. Do not place private credentials, participant records, proprietary source, or restricted deployment artifacts in this repository.

## Sharing Rule

References to M5 implementations in Foundation materials must be clearly labeled as implementation-specific, external, and subject to separate terms. Foundation standards remain implementation-neutral and are not owned or controlled by any one implementation merely because that implementation participates in public review.
