# Changelog

This file records material public changes to the ICSN standards workspace. Standards status is governed by `GOVERNANCE.md`; a repository release does not by itself advance a proposal to Candidate or Stable.

## [0.1.0] - 2026-08-18

### Added

- Foundation governance, participation, membership, security and contribution materials.
- Explicit Apache-2.0, CC-BY-4.0 and Cyrus Public Review Draft asset-level licensing structure.
- Human-rooted identity, agent-operations and public-review specifications.
- Founding-role map, M5 activation pilot, M5isYOU profile model and fair-matching safeguards.
- Sophia public-review registry covering 636 roles across 37 tracks.
- Instructor and curriculum activation pathway.
- Ricardian service-contract model and schemas.
