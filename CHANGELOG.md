# Changelog

This file records material public releases of the ICSN standards workspace. Standards status is governed by `GOVERNANCE.md`; publication does not by itself advance a proposal to Candidate or Stable.

## [Unreleased]

### Added

- Planned DUNA commons-governance roadmap, clearly marked as future/not yet activated.
- Ricardian three-part agreement standard separating human terms, machine-readable meaning, and bounded execution.

- Canonical M5IAM / TCID / M5HUM authority architecture.
- M5-CV / SOPHIA capability and credential architecture.
- M5Canon Six-Gate authority and transfer-control reference.
- M5MST asset-minting and TitleChain-registration reference for WyomingChain.eth.
- JNR, SwiftBRIDGE, M5 Global Index and Exchange, L0–L8/ZK, bridge-proof, title-certificate, custody, and authority-registry public reference material.

### Changed

- Public M5 materials use the canonical IAM → M5HUM → M5POD → M5-CV/SOPHIA → bounded M5AGT relationship.
- Public taxonomy reserves M5HUM for the Human Principal, M5AGT for the Autonomous Agent, M5AST for the five-tier Asset Token, and M5MST for the asset-minting or TitleChain-registration event.
- Public economic architecture separates M5 asset/economic classification from M5Bank account contexts and external legal/regulatory status.
- Repository navigation leads agency and technical reviewers directly to authority, origination, transfer, jurisdiction, and evidence/conformance material.

### Planned

- Conformance test vectors and implementation evidence for selected standards.
- Security, privacy, transfer-agent, statistical-methodology, and accessibility review.

## [0.1.0] - 2026-08-18

- Foundation governance, participation, membership, security, and contribution materials.
- Human-rooted identity and accountable-agent public-review specifications.
- SOPHIA public-review role registry, activation/curriculum materials, and Ricardian service-contract model.
