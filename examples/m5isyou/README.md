# M5isYOU examples

These examples demonstrate the public shape of a holder-controlled capability passport. They contain no real applicant record and should not be used to submit private information through GitHub.

- `blank-profile.md` — a safe copyable one-page structure
- `founder-builder-example.md` — a clearly fictional example showing the intended level of detail

Use the private M5 Member Activation application for an actual participant profile.
