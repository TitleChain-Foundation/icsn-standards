## Status vocabulary

- **Draft:** open proposal under public review.
- **Candidate:** sufficiently specified for independent implementation and conformance testing.
- **Stable:** approved under Foundation governance with implementation and review evidence.
- **Deprecated:** retained for history but no longer recommended.

## Propose an RFC

1. Start with a Discussion to test the problem statement and recruit reviewers.
2. Copy `0000-template.md` and request an RFC number in a pull request.
3. Identify human authority, privacy, security, accessibility and exit implications.
4. Define conformance criteria and implementation evidence.
5. Follow `GOVERNANCE.md` for status changes and recorded decisions.
